# Red Carbon

Palette and preview supplied by CyberShonk from the Red Carbon mainline design system: A2R Coherent Micro-Pebble Matte, Droid Chamfer and Red Gasket. The preview is the supplied `A2R_selected_blank_512.png`, unchanged.

The native app registers the dark theme locally. Graphite surfaces stay flat for readable transcripts; red marks active controls, selection and focus. Small semantic text uses brighter shades for contrast. This does not register a host or desktop preset.
